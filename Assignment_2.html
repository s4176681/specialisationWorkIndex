When creating a system that encourages studying and supporting external activity, I'd like to think about how the user would interact with the UI between intervals. I found this concept quite interesting and relatable, and balancing the time on and off the interaction will be a challenge. Many users have a method for listening to music while focusing on another task. The initial purpose that came to mind is how the instrument would fulfil its task as a source of entertainment without taking too much of the user’s time and concentration. By directing the sound's dynamics in this way, the application aims to help the user achieve their goals, not sidetrack them. This then makes the value and weight of the instrument complementary to the user’s goals. Studying is the scenario I’d like to explore, which may embody a collection of sounds and controls for the user to choose from. By completing this step, the instrument essentially falls into dynamic background noise for the user to enjoy. In the near future, the most considered extended technique would involve either spatial inputs or time relevant variables as mentioned before.
