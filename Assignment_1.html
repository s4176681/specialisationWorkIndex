Design Scenario

Dynamic Soundtrack-er

Many different situations, such as studying, exercising or table top role playing, may benefit from a soundtrack that can respond to their unfolding solo or group dynamics. While users' inputs may be minimal or over long intervals, users should still be able to meaningfully interact with the instrument.

Design Response

When creating a system which encourages studying and supporting external activity, I'd like to think about how the user would interact with the UI between intervals.
