Design Scenario response

Dynamic Soundtrack-er

When creating a system that encourages studying and supporting external activity, I'd like to think about how the user would interact with the UI between intervals. I found this concept quite interesting and relatable, and balancing the time on and off the interaction will be a challenge. Many users have a method for listening to music while focusing on another task. The initial purpose that came to mind is how the instrument would fulfil its task as a source of entertainment without taking too much of the user’s time and concentration. By directing the sound's dynamics in this way, the application aims to help the user achieve their goals, not sidetrack them. This then makes the value and weight of the instrument complementary to the user’s goals. Studying is the scenario I’d like to explore, which may embody a collection of sounds and controls for the user to choose from. By completing this step, the instrument essentially falls into dynamic background noise for the user to enjoy.

Overview

I aim to create a system which adopts simple musical interactivity whilst acting as a background source of emotion. This gives the user gratification while also acting as a media player-like browser application. The difference between this and a music player would be how the user’s actions outside of the instrument influence its sounds. An example would be if a calming loop was playing as a student was studying, but an extended period of inactivity would slow down and reverb the existing loop. Users would interact with the instrument by experimenting with a preset of noises set in different key signatures.

Design Framing

The scope of the assignment; the number of controls needs to be considered to ensure users don’t overspend time. Ensure that they are not overwhelmed by its complexity. Add a sense of familiarity by basing elements on a media player or a music-finder app. To play sounds if the tab is open, or to maintain an ‘on’ state even when the user is away from the device. As for creating sounds and satisfying loops, copyright-free sounds will be used to revamp and adjust to the user's liking. Furthermore, a little bit further out of the project's scope would be to create a keyboard that can generate repeating rhythms and loops that are placed on a track for the user to experiment with.
